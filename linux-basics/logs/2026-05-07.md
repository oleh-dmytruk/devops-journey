Bash Scripting

Running Commands
Bash executes commands line by line.
Every command returns exit code: 0 = success, anything else = error.
echo $? - show exit code of last command
&& - run next command only if previous succeeded
|| - run next command only if previous failed
; - run next command anyway

Scripts
Script - file with commands that bash executes from top to bottom.
First line: #!/bin/bash - shebang, tells system which interpreter to use.
chmod +x script.sh - make file executable
./script.sh - run script from current directory

Variables
NAME="value" - no spaces around =
$NAME or ${NAME} - access variable
${NAME} preferred when variable is inside text: "${NAME}_backup"
Local vs environment variables:
- Regular variable - only in current script
- export VAR=value - available to child processes
$1 $2 $3 - positional arguments passed to script
$# - number of arguments
$@ - all arguments

Conditional Operators
if [ condition ]; then
    commands
elif [ condition ]; then
    commands
else
    commands
fi

Comparisons:
- Numbers: -eq -ne -lt -gt -le -ge
- Strings: = != -z (empty) -n (not empty)
- Files: -f (exists as file) -d (exists as dir) -r (readable)

Example: if [ -f /etc/passwd ]; then echo "exists"; fi

Pipelines & Logical Operators
Pipeline - output of one command becomes input of next.
| - pipe symbol
ps aux | grep nginx - find nginx in process list
cat log.txt | grep ERROR | wc -l - count errors in log

Logical operators in scripts:
&& - AND, both must be true
|| - OR, at least one true
! - NOT, inverts condition
[ -f file ] && echo "exists" || echo "not found"
