Python Basics

Virtual Environment
venv isolates Python packages per project.
Without venv all packages install globally and can conflict between projects.
python3 -m venv myenv - create environment
source myenv/bin/activate - activate it
deactivate - exit environment
pip freeze > requirements.txt - save dependencies
pip install -r requirements.txt - install from file

Datatypes and Basic Operations
Main types: int, float, str, bool, None
type(x) - check type of variable
int("5") - convert string to int (casting)
str(5) - convert int to string
String formatting: f"Hello {name}" - f-strings, modern way
Operators: + - * / // % **
// - integer division (5 // 2 = 2)
% - remainder (5 % 2 = 1)
** - power (2 ** 3 = 8)

Lists, Sets, Tuples and Dicts
List - ordered, mutable, allows duplicates
my_list = [1, 2, 3]
list.append(x), list.remove(x), list.pop()

Tuple - ordered, immutable, allows duplicates
my_tuple = (1, 2, 3)
Used when data should not change.

Set - unordered, mutable, no duplicates
my_set = {1, 2, 3}
Useful for removing duplicates from a list: set(my_list)

Dict - key-value pairs, mutable
my_dict = {"name": "server1", "ip": "192.168.1.10"}
my_dict["name"] - access value by key
my_dict.keys(), my_dict.values(), my_dict.items()

When to use what:
- List - when order matters and you need duplicates
- Tuple - when data is constant
- Set - when you need unique values
- Dict - when you need to find data by key
